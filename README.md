## Sobre a disciplina

Nesta disciplina estudo a forma como os computadores são constituídos, como funcionam internamente e de que modo o hardware e o software comunicam entre si.

## Objetivos

- Compreender os principais componentes de um computador.
- Conhecer a organização e o funcionamento de um sistema computacional.
- Relacionar conceitos teóricos com exemplos práticos.
- Registar a minha evolução e as aprendizagens feitas ao longo das aulas.
